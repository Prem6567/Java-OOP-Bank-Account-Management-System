Java OOP Bank Account Management System

📌 Project Overview

The Bank Account Management System is a console-based Java application designed to simulate basic banking operations. It demonstrates fundamental Object-Oriented Programming (OOP) concepts while providing a simple and interactive banking experience.

Users can create a bank account, deposit money, withdraw money, check their account balance, and view account details.

🚀 Features

- Account Creation: Enter the account holder's name and account number.
- Deposit Money: Deposit money into the account with input validation.
- Withdraw Money: Withdraw money while checking the available balance.
- Balance Inquiry: Check the current account balance.
- Account Details: Display account information and balance.
- Input Validation: Handle invalid menu choices, invalid amounts, negative initial balances, and insufficient funds.
- Interactive Menu: Navigate banking operations through a simple console menu.

🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Scanner Class
- Conditional Statements
- Loops and Switch Statements
- Encapsulation
- Constructors

⚙️ How to Run

🧠 OOP Concepts Demonstrated

Encapsulation

Account information and balance are stored in private fields and accessed through class methods.

Constructors

The "BankAccount" constructor initializes the account holder's name, account number, and initial balance.

Classes and Objects

The "BankAccount" class represents a bank account, while an object is created to perform banking operations.

Methods

Separate methods handle deposits, withdrawals, balance inquiries, and account details.
